# MediClarity - IB CS HL IA
## Description
An iOS app that allows you to track your medications, and scan products for harmful ingredients or ingredients you are allergic to.
## Success Criteria:
1. The application should be able to access an uploaded photo
2. The application should be able to scan and identify text
3. The application should be able to store data of the user’s allergies
4. The application should be able to notify user if any ingredients match those of their allergies or harmful ingredients
5. The application should be able to save username and password information
6. The application should have a functional login page
7. The application should have a database with information of FDA’s not-approved substances
8. The application should have a medication logger, where user can log all of their medications
9. The application should be able to have user input times when to take medications, Should be able to have daily repeated schedules of medication logs
